Privacy Policy

The Cardano Record

Last updated: 9 September 2026

This policy covers the website at elliot-agento.github.io/cardano-record and the private publishing automation ("the Application") used to upload videos to the YouTube channel @CardanoRecord.

Summary. The Application is a single-user tool. It signs in only as its own operator, in order to upload videos to a channel that operator owns. It does not collect, request, store or process personal data belonging to anyone else, and it shares no data with third parties.

1. Who operates this

The Application and channel are operated by one independent individual. There is no company, no team and no third-party processor. It is not affiliated with the Cardano Foundation, Input Output, Intersect, Indigo Protocol, Google or YouTube.

2. Google user data the Application accesses

The Application uses the YouTube Data API v3 and requests these OAuth scopes, for the operator's own Google Account only:

  • youtube.upload — to upload video files to the operator's channel.
  • youtube — to read the channel's own identity, and to set video metadata such as title, description, tags and thumbnail.
  • youtube.force-ssl — to attach caption tracks to the operator's own videos.

No other Google API, product or scope is used. The Application never requests authorisation from any other person, and no other person can sign in to it.

3. How that data is used

Solely to publish the operator's own video content to the operator's own channel. The Application reads the channel's name, ID and public statistics to confirm it is uploading to the correct destination, and writes videos, thumbnails, captions and metadata. It performs no other action on the account.

4. How that data is stored

The OAuth refresh token issued by Google is stored in a single file on the operator's own computer, readable only by the operating-system account that runs the Application (permissions 0600). It is not transmitted anywhere except to Google's own authentication endpoints, is not stored in any cloud service, database or version-control repository, and is not backed up off the machine.

No Google user data is retained beyond that credential and the operator's own published video files.

5. Sharing and transfer

No Google user data is sold, rented, shared, transferred or disclosed to any third party. It is not used for advertising, profiling, or to train machine-learning or AI models, and it is not transferred to any other application or service.

6. Retention and revocation

The credential is retained only while the channel is active. The operator can revoke the Application's access at any time at myaccount.google.com/permissions, which immediately and permanently invalidates it; the local file is then deleted. Since no data belonging to any other person is collected, there is nothing further to delete on anyone else's behalf.

7. This website

The site is static and hosted on GitHub Pages. It sets no cookies, runs no analytics, embeds no trackers and has no comment system, contact form or login. GitHub may log ordinary web-server request data (such as IP address) as part of serving the page; see GitHub's Privacy Statement. The operator receives no such data.

8. YouTube viewers

Watching videos on YouTube is governed by Google's Privacy Policy and the YouTube Terms of Service, not by this policy. The operator can see only the aggregate, anonymised statistics YouTube provides to any channel owner, and does not attempt to identify individual viewers.

9. Children

The channel is not directed to children, and its videos are not designated as made-for-kids.

10. Changes

Material changes to this policy will be published on this page with an updated date above.
